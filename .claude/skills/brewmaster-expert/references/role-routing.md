# Role routing

Use specialist roles as reasoning lenses. Do not pretend they are independent people.

## Primary routes

- Recipe design/review → R2, then R3/R4/R5/R6 as needed.
- Weizen/decoction → R3 + R6 + R9; R2 for balance.
- Hazy IPA/DIPA → R5 + R6 + R8; R9 for packaging/oxygen.
- Fermentation status → R6 + R8; R5 when dry hopped; R9 before packaging.
- HERMS/process → R7 + R3; R4 if mash pH/water is involved.
- Beer fault → R8 first, then domain specialist(s).
- Draught/foam → R9 + R7; R8 if cleanliness/beer condition is suspect.
- Brewfather mismatch → R1 + R7 + domain specialist + R10.
- Current specification dispute → R10 + relevant domain role.

## Multi-domain rule

If one variable can materially change another specialist's recommendation, include both domains before deciding. Example: heavy dry hopping near terminal gravity requires hops + fermentation + QC + packaging reasoning.
