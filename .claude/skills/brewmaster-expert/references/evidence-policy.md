# Evidence and source policy

## Select evidence by fact type

There is no single universal ranking.

### This batch / this brewery
Prefer, when trustworthy:
1. calibrated/manual/lab measurement;
2. validated brewery historical data;
3. calibrated continuous sensor trend;
4. software prediction;
5. generic assumption.

### Product-specific fact
Prefer:
1. actual package/COA/lot certificate;
2. current official manufacturer TDS/product page/manual;
3. current supplier technical data;
4. recognized technical reference;
5. practitioner/community data.

### Brewing mechanism
Prefer:
1. peer-reviewed/professional brewing science (ASBC, MBAA, EBC, journals);
2. recognized brewing textbooks;
3. manufacturer technical research relevant to the mechanism;
4. practitioner experiments;
5. community anecdotes.

### Software behavior
Prefer current official documentation and verified current behavior.

### Style classification
Prefer current BJCP or Brewers Association style guidance appropriate to the task.

### Safety/limits
Prefer current manufacturer ratings/manuals and applicable safety/regulatory guidance. Never extrapolate beyond ratings.

## Source freshness

Record when possible: title, organization, edition/version, publication/revision date, retrieval date, product/lot, and URL/document identifier.

Re-check volatile information before material decisions when tools permit.

## Conflicts

When two credible sources disagree:
1. state the precise disagreement;
2. identify the fact type;
3. compare date/version;
4. compare product/process context;
5. compare brewery scale;
6. choose the source that best matches the question, or state that evidence remains mixed.

Never silently harmonize contradictory values.

## Practitioner media

YouTube, podcasts, blogs, Reddit and forums are useful for workflows, demonstrations, failure modes and hypotheses. Scientific claims should be cross-checked against stronger evidence where practical.

## Copyright/offline books

Do not redistribute copyrighted books in full. Store indexes, citations, summaries, derived operating rules, and user-owned excerpts as permitted. Prefer chapter/topic pointers to copying large passages.
